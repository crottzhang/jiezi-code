# Jiezi Code

基于 Tauri 2 + Vue 3 + CodeMirror 6 的轻量代码编辑器。

## 开发

```bash
npm install
npm run tauri dev     # 开发
npm run tauri build   # 打包
```

## 结构

```
src-tauri/src/
  fs.rs         文件读写、目录读取（按需一层）、新建/重命名/删除到回收站
  window.rs     多窗口：同一进程内开新窗口，共享 WebView2 浏览器进程
  terminal.rs   终端：portable-pty（Windows 下为 ConPTY + PowerShell），输出走 Channel 原始字节
  git/          Git：调用系统的 git 命令行（沿用用户的配置、钩子和凭据）
    status.rs     状态（porcelain v2）、暂存（含只暂存一处改动）、提交、撤销提交、.gitignore
    history.rs    提交历史、提交改动的文件、逐行作者信息、还原/拣选提交、标签
    branch.rs     分支列表、切换/新建/删除/重命名、合并，合并/变基进行中时继续或中止
    stash.rs      储藏
    remote.rs     拉取/推送/抓取/克隆：实时进度、可取消
  askpass.rs    远程操作需要账号密码时，本程序充当 GIT_ASKPASS，把问题转给编辑器弹窗
  watch.rs      监听打开的文件夹，外部改动时通知前端刷新文件树、已打开的文件和 Git 状态
  notes.rs      笔记：SQLite（rusqlite，内置 SQLite），所有窗口共用一个连接，改动后广播 notes-changed
src/
  api/                  Rust 命令的前端封装
  editor/setup.ts       CodeMirror 配置、语言包按需加载
  editor/quickDiff.ts   行号旁的 Git 改动标记
  editor/conflicts.ts   合并冲突的“采用当前/采用传入/保留双方”按钮
  editor/blame.ts       光标所在行末尾的作者信息
  store/workspace.ts    文件夹、标签页、保存等核心状态
  store/terminal.ts     终端会话列表、显示/隐藏
  store/run.ts          运行视图：常用命令（按文件夹保存）和它自己的终端列表
  store/notes.ts        笔记列表、搜索、新建/置顶/删除，同步其他窗口的改动
  store/git.ts          Git 状态、文件监听、暂存/提交/同步、合并进行中的继续/中止、克隆
  store/diff.ts         行内/并排对比、只暂存一处改动、行号旁改动标记的数据
  store/branches.ts     分支选择、新建、删除、重命名、合并
  store/stash.ts        储藏列表与操作
  store/history.ts      提交历史、文件历史、还原/拣选/打标签
  store/blame.ts        读取行作者信息
  store/output.ts       Git 输出日志
  store/layout.ts       侧边栏视图、侧边栏/终端面板宽度（持久化）
  store/ui.ts           输入框、右键菜单、提示
  components/           活动栏、文件树、源代码管理、标签栏、编辑器、终端面板、状态栏、欢迎页
```

布局：`活动栏 | 侧边栏 | 编辑区 | 终端面板`，底部状态栏。

## 源代码管理

活动栏第二个图标（Ctrl+Shift+G）打开 Git 面板：

- 按“合并更改 / 暂存的更改 / 更改”分组列出文件，可以暂存、取消暂存、放弃更改（未跟踪的文件移到回收站）。
- 点击文件显示差异：未暂存的更改与暂存区对比，已暂存的更改与 HEAD 对比。编辑器上方的对比栏可以跳到上一处/下一处、切换行内/左右并排显示、关闭对比。
  行内对比时每处改动旁有“暂存”（只暂存这一处）和“还原”按钮；并排对比时左边的箭头还原这一处。
- 平时编辑时，行号旁用绿色/蓝色竖条和红色三角标出与暂存区相比新增、修改、删除的行，点击标记查看这一处的差异。
- 光标所在行末尾淡淡显示这一行的作者、时间和提交说明（未保存的修改也能正确对应），可在“Git”菜单里关闭。
- 提交按钮右侧的下拉菜单：提交并推送、提交并同步、修改上次提交（把上次的提交信息填进输入框再改）、撤销上次提交（改动回到暂存区）。
- 合并、变基、拣选、还原有冲突时，冲突块上方有“采用当前更改 / 采用传入更改 / 保留双方”按钮；面板顶部提示进行中的操作，可以继续或中止。
- 分支：切换（本地和远程分支，远程分支自动建立跟踪）、新建、基于其他分支新建、合并到当前分支、重命名、删除（没合并时会再次确认是否强制删除）。
- 储藏：储藏改动（可包含未跟踪的文件）、应用、弹出、删除，展开可查看其中的文件并对比。
- 拉取/推送/抓取/克隆显示实时进度，可以在状态栏取消。需要账号密码或 SSH 口令时弹出输入框（装了 Git Credential Manager 时由它自己弹窗）。
- 资源管理器里的文件和文件夹按 Git 状态着色；右键未跟踪的文件或文件夹可以“添加到 .gitignore”。
- 面板底部的“历史记录”列出提交（每次 50 条，可加载更多），点标题上的分支名可以查看其他分支的历史。展开提交可以看到改动的文件，点击文件以只读标签页打开该版本并与父提交对比。右键提交可以复制哈希/提交信息、新建分支、打标签、还原此提交，查看其他分支时可以拣选到当前分支。
- 在资源管理器、标签页或更改列表里右键文件选“查看文件历史”，历史记录只显示改动过这个文件的提交（跟随重命名）。
- 所有修改仓库的 git 命令及其输出都记录在“Git 输出”里（出错提示上有“查看输出”）。
- 文件夹和 .git 目录的变化由文件监听实时发现（包括终端里执行的 git 命令），窗口获得焦点时也会刷新。

需要系统里装有 git 并加入 PATH。

## 运行

活动栏第四个图标（Ctrl+Shift+D）打开运行视图，和右边的终端面板相互独立：

- 上方列表保存常用命令（每个文件夹各自一份）：点 ＋ 添加，悬停时可以编辑、删除。
- 点击命令会在视图下方开一个新终端（Run 1、Run 2…），在打开的文件夹下执行。
- 收起侧边栏或切换到其他视图时，运行中的终端继续运行。

## 笔记

活动栏第五个图标打开笔记视图（也可以在菜单“文件 → 新建笔记”）：

- 笔记用 Markdown 写，在编辑器标签页里打开；停止输入 1 秒后自动保存，Ctrl+S 立即保存。
- 第一行非空文字是标题，下一行是列表里的摘要；可以按标题或正文搜索，可以置顶。
- 标签页右键“打开预览”查看渲染后的效果。
- 笔记不属于某个文件夹，保存在应用数据目录下的 `notes.db`（Windows 下为 `%APPDATA%\com.jiezi.code\notes.db`），第一次用到笔记时才创建。

## 主题

`src/theme/themes.ts` 定义了两套主题（VS Code Dark Modern、Linear），每套是一组 CSS 变量加一份终端配色。
界面、CodeMirror 语法高亮都只引用 CSS 变量，切换主题时只改 `:root` 上的变量，不重建编辑器状态。
加新主题：在 `themes` 数组里加一项即可，菜单和命令面板会自动出现。

## 命令行

```bash
jiezi-code <文件夹>   # 打开文件夹
jiezi-code <文件>     # 打开所在文件夹并打开该文件
```

## 省内存的设计

- 整个窗口只有一个 `EditorView`，每个标签页只保存一个不可变的 `EditorState`（包含撤销历史），切换标签页时替换状态。
- 语言高亮通过 `@codemirror/language-data` 动态 import，打开某种文件时才加载对应的语言包。
- 文件树只在展开目录时读取这一层，不扫描整个项目。
- 终端面板（含 xterm.js）是异步组件，第一次按 Ctrl+` 时才加载并启动 PowerShell。
- 行内差异视图（@codemirror/merge）在第一次打开对比时才加载。
- 多个项目用 Ctrl+Shift+N 开新窗口：同一个进程，WebView2 的浏览器/GPU 进程共享，每多一个窗口只多一个渲染进程。
